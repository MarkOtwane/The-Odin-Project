# Recipe Project

## Introduction

This project is a collection of simple recipes for making **Chapati**, **Chicken**, and **Rice**. The goal of this project is to demonstrate basic HTML skills by creating structured recipe pages, including ingredient lists, step-by-step instructions, and short descriptions for each dish.

## Recipes Included

- **Chapati** – Soft, flaky flatbreads made from wheat flour.
- **Chicken** – A flavorful, seasoned chicken recipe with common spices.
- **Rice** – Perfectly cooked rice to accompany any meal.

## Skills Demonstrated

By completing this project, I have practiced and showcased the following skills:

- Writing clean and semantic HTML.
- Structuring content with lists, headings, and paragraphs.
- Writing concise, user-friendly descriptions.
- Organizing multiple recipe pages within a single project.

## Future Improvements

- Add CSS styling to make the recipe pages visually appealing.
- Include images for each step to make the instructions easier to follow.
- Add JavaScript for interactive features, such as ingredient checklists or timers.
